---
name: completion-checks
description: Check file completeness, references, and task coverage before delivering office-work artifacts.
---

After editing files, reopen the final versions and compare them with the user's requirements. For spreadsheets, check formulas and references; for documents, check structure and content; for presentations, check layout and readability.

Report only checks that were actually performed. If the available tools cannot inspect a property, state that limitation instead of presenting an assumption as a confirmed result.
