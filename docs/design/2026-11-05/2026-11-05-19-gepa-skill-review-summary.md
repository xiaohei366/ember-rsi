## Confirmed decision 49: Include a concise explanation of skill changes

Add a short skill-change explanation to the human review report. Describe which reusable rules changed and which observed problems those changes address, and provide links or paths to the relevant skill files used by the development attempt under review.

Associate the explanation with the actual skill version and its selected proposal base, including when that base is a historical version. Use the available proposal rationale and skill artifacts to prepare the explanation. Do not present an untested later proposal as the skill that produced the reviewed GEPA implementation.

The Evaluator prepares this material alongside its existing review summary, and the human-review plugin presents it. Keep the explanation brief so the user can assess whether the changes are suitable for general Policy and plugin development and inspect the linked files when needed.

This presentation supports human judgment; it does not establish generalization from the single GEPA development task. It does not expand the Proposer's edit scope or change the development-only cost feedback. Report preparation remains outside that cost.
